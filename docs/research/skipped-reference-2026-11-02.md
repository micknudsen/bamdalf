# Skipped reference regions in CIGAR

Research date: 2026-11-02. Supporting evidence for Q53, accepted on the same date. Checked the official SAM v1.6 specification, printing `b5341fb`, dated August 12, 2025. [design.md](../design.md) is the authority for current display requirements.

## Verified semantics

- CIGAR `N` skips a reference interval. Its length advances the reference position without advancing the query position. `D` has the same consumption pattern but denotes a deletion; these are distinct operations. [SAM specification, §1.4, CIGAR table](https://samtools.github.io/hts-specs/SAMv1.pdf#page=8)
- For mRNA aligned to a genome, `N` represents an intron. The specification leaves its interpretation in other alignment types undefined. An arbitrary `N` therefore cannot be labeled automatically as an intron or recast as `D`. [SAM specification, §1.4, CIGAR notes](https://samtools.github.io/hts-specs/SAMv1.pdf#page=8)
- CIGAR `N` is separate from the nucleotide code `N` stored in `SEQ`; the latter is a sequence symbol, not an instruction to skip reference coordinates. BAM encodes CIGAR operations and sequence symbols in separate fields. [SAM specification, §4.2 and §4.2.3](https://samtools.github.io/hts-specs/SAMv1.pdf#page=15)

## IGV Desktop comparison

Checked source commit `f4b78d6412fa31eaca9b5bad7b3c35a8925828da` and official documentation on 2026-11-02. This was source inspection, not a running-application test or a check of the user's preferences.

- **`N`:** a thin, straight blue-gray connector between alignment blocks, with RGB `(150, 184, 200)`. The gap renderer uses `drawLine` and does not assign a dashed stroke to `N`. Pixel endpoints follow the skipped genomic interval, clipped to the view. This agrees with the documentation's thin blue line for RNA split-read blocks. [Color definition](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L75-L80), [coordinates and drawing](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L603-L644), [RNA documentation](https://igv.org/doc/desktop/UserGuide/tracks/alignments/rna_seq/#rna-seq-alignments)
- **`D`:** a straight solid connector, documented as a black bar in the ordinary light-theme display. The source defines the deletion color as panel foreground and switches to a solid 2-pixel stroke when the alignment body is taller than 5 pixels. For smaller bodies it retains the ordinary gap graphics. [Deletion documentation](https://igv.org/doc/desktop/UserGuide/tracks/alignments/viewing_alignments_basics/#indels), [stroke definition](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L263-L264), [gap branches](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L631-L644)
- **Size labels:** default settings enable indel labels above 1 base. The gap-label branch applies to `D`, not `N`, and displays a deletion length only when the text fits. [Defaults](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/resources/preferences.tab#L156-L160), [deletion-only label condition](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L646-L648), [fit condition](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L1158-L1172)

The `N`/`D` color branch does not depend on experiment type. RNA defaults additionally enable a **separate splice-junction track**, whose red/blue strand-colored arcs must not be confused with individual-read connectors. General defaults used for ordinary short-read DNA disable that extra track. [General default](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/resources/preferences.tab#L99-L104), [RNA override](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/resources/preferences.tab#L192-L204), [junction-track documentation](https://igv.org/doc/desktop/UserGuide/tracks/alignments/rna_seq/#splice-junction-track)

Source caveat: the tall-deletion branch selects the shared thick-stroke graphics after setting the color on the ordinary gap graphics; it does not explicitly set the replacement graphics' color there. Thus the documented black deletion convention is better supported than a guarantee of the exact color on every rendering/theme path. [Graphics switch](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/alignment/AlignmentRenderer.java#L638-L644), [graphics-cache creation](https://github.com/igvteam/igv/blob/f4b78d6412fa31eaca9b5bad7b3c35a8925828da/src/main/java/org/igv/track/RenderContext.java#L77-L86)

## Design implication

Q53 distinguishes true-width `N` gaps from `D` gaps with blue-gray and foreground-color connectors. This follows IGV's familiar color distinction; it is not a SAM requirement, a biological inference beyond the recorded operation, or a promise to reproduce every IGV rendering detail. See [design.md](../design.md) for the display contract. No implementation or BAM inspection was performed.

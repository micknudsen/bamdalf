# Project guidance

Before changing persisted formats or adding compatibility behavior, read
[the pre-1.0 compatibility policy](CONTRIBUTING.md#pre-10-compatibility-policy).

For reference creation or bundle naming changes, read the
[confirmed creation-window design](docs/reference-creation-design.md) and its
[delivery evidence](docs/reference-creation-acceptance.md); distinguish accepted
behavior, the historical baseline, and verified implementation.
